# MultiView

A Picture-in-Picture, floating windowed, and 50/50 split-screen streaming overlay designed for Android TV. Watch YouTube, Twitch, or web streams simultaneously while gaming on emulators (DraStic, MyBoy) or navigating other TV apps.

## Features

- **4 View Modes:**
  - **PiP (Corner):** 640×360 floating window in any corner.
  - **Windowed:** 1120×630 centered floating window.
  - **Split Screen (50/50):** True dual-pane side-by-side layout (Left: Web/Browser, Right: YouTube/Stream).
  - **Full Screen:** Standard full 1080p stream view.
- **Remote / Gamepad Focus Switcher:** Toggle D-pad and controller routing between Video, Browser, and Game with zero input delay or ghost key presses.
- **Built-in Ad-Blocker:** Intercepts ad networks and auto-skips video ads.
- **Account Sync:** Persistent cookies support Google and YouTube Premium login.
- **Dock Card Contract:** Integrates as a dock card tile in the CleanYourTV launcher.
